# 🎬 Movie App — Android Application

A simple and elegant Android Movie App built using **Java** in **Android Studio**, allowing users to browse and explore movies easily.

---

## 📱 Features

- 🎥 Browse list of movies
- 📋 View movie details (title, description, rating)
- 🔍 Search for movies
- 🖼️ Movie poster display
- 📱 Clean and responsive UI

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Java | Programming Language |
| Android Studio | Development IDE |
| XML | UI Layout Design |
| ListView / RecyclerView | Displaying movie list |
| ArrayAdapter | Data binding |

---

## 🚀 How to Run

1. Clone the repository
```bash
git clone https://github.com/poojasenthil06/Movie_app.git
```
2. Open in **Android Studio**
3. Let Gradle build finish
4. Click **Run ▶️** or press `Shift + F10`
5. Choose an emulator or connect your Android phone
